# JavaScript Learning Projects

This folder contains a collection of small web projects that I built while learning JavaScript. These projects focus on core concepts such as DOM manipulation, timers, interaction, styling, and basic front-end development.

## Projects

- Countdown Timer
  - A simple countdown application built with HTML, CSS, and JavaScript.

- Digital Clock
  - A basic digital clock that updates in real time.

- Hex Flipper
  - A small interactive project that changes colors using hexadecimal values.

## Purpose

These projects are part of my learning progress as I continue to improve my understanding of JavaScript and front-end development.

## How to Use

Open any project folder and open the HTML file in a browser to view the project.
